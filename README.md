# solocam

Виртуальная камера для созвонов, которая оставляет в кадре **только вас**. Люди, которые
ходят за спиной или заглядывают в камеру, вырезаются вместе с фоном.

Штатные фильтры (Google Meet, Яндекс Телемост, Zoom, NVIDIA Broadcast, XSplit VCam,
OBS-плагин Background Removal) решают другую задачу: отделить «человека» от «не человека».
Для них все люди в кадре один класс, поэтому второе лицо всегда попадает в поток.
solocam различает людей и следит за одним конкретным.

Требования: Windows 11 (виртуальная камера через `MFCreateVirtualCamera`), NVIDIA GPU
(проверено на RTX 3060: 27–29 кадров/с при 1280×720), Python 3.12.

## Как работает

1. **YOLO11-seg + ByteTrack** — каждому человеку своя маска и постоянный номер.
2. **Захват цели** — при старте самый крупный человек в кадре; дальше фильтр держит его
   номер. Если трекер потерял номер, цель ищется по положению; на чужого человека в другом
   месте кадра фильтр не переключается. Если в кадре один человек, это цель без вопросов.
3. **Robust Video Matting** — чистый контур волос и плеч. Его альфа умножается на маску
   цели (расширена на 9 px, край сглажен на 21 px) **минус маски остальных людей**.
   Так посторонний вырезается, даже если RVM его оставил, а кресло не тянется за головой.
4. **Линия отсечки по плечам** — YOLO11-pose находит нос и плечи; всё ниже плеч на 0.8
   расстояния «нос–плечи» становится фоном: остаются голова, плечи и верх корпуса, руки не
   мелькают. Линия следует за посадкой, сглажена. Если плечи не видны, берётся запасная
   линия `--cut` (доля высоты кадра). Отключается `--cut 1`.
5. Результат уходит в виртуальную камеру Windows 11 **solocam** — для Meet, Телемоста, Zoom,
   Telegram и любого приложения это обычная веб-камера.
6. **Работа по требованию.** Windows сама сообщает, кто сейчас снимает с какой камеры
   (`IMFSensorActivityMonitor`, на нём же значок «камера используется»). Пока камеру
   **solocam** никто не открыл, реальная веб-камера закрыта, а PyTorch, CUDA и нейросети
   даже не загружены: фоновый процесс занимает ~20 МБ памяти. Приложение открыло камеру —
   solocam запускает дочерний процесс с нейросетями, первая картинка через ~8–12 с;
   закрыло — через 5 с веб-камера закрывается, а модели выгружаются из видеопамяти.
   Дочерний процесс ждёт ещё 2 минуты (повторное открытие камеры — картинка через ~2 с),
   потом завершается и отдаёт системе всю память (~2,6 ГБ).
   Чтобы на созвоне картинка была сразу, нажмите **«Подготовить к звонку»** (панель в трее
   или `POST /prepare`): solocam заранее включает веб-камеру и фильтр, захватывает вас,
   через ~10 с значок голубой — «камера включена, готово». Приложение для звонка получает
   живую картинку меньше чем за секунду. Пока solocam готов, веб-камера занята для других
   программ. Если звонок за 10 минут не начался, веб-камера и память освобождаются сами;
   повторное нажатие продлевает ещё на 10 минут, «Выход» выключает всё.
   Если веб-камера отвалилась (USB, сон), solocam переоткрывает её сам.

Скорость: поиск людей идёт в отдельном потоке и CUDA-стриме, RVM записан как CUDA-граф
(на Windows PyTorch в обычном режиме упирается в запуск операций: 14 мс → 6 мс на кадр).

## Установка

```bat
git clone https://github.com/GhostOfCommunism/solocam
cd solocam
setup.bat
```

`setup.bat` создаёт `.venv`, ставит PyTorch (CUDA 12.6), ultralytics, при необходимости
ffmpeg через winget и регистрирует виртуальную камеру (один запрос UAC). Веса YOLO (`yolo11s-seg.pt` 20 МБ, `yolo11n-pose.pt` 6 МБ)
и RVM скачиваются при первом запуске.

Виртуальная камера — это COM-библиотека `vcam\VL.Video.VCamSource.dll`, её загружает служба
Windows Frame Server. Это media source из [VL.Video.VirtualCamera](https://github.com/bj-rn/VL.Video.VirtualCamera)
(MIT), собранный из исходников зафиксированного коммита: `vcam\build.cmd` пересобирает его
(нужны .NET 8 SDK и VS 2022 Build Tools). `vcam\register.cmd` (от администратора) копирует DLL
в `C:\ProgramData\vvvv\VirtualCamera` и регистрирует; `vcam\unregister.cmd` — удалить.
Кадры идут через общую память (`vcam.py`, только stdlib `ctypes`).

## Запуск

```bat
run.bat --preview
```

Откроется окно предпросмотра с зелёной рамкой вокруг того, за кем следит фильтр.
Клавиши (окно должно быть в фокусе, раскладка английская): `r` — заново выбрать самого
крупного человека, `q` / `Esc` / крестик — выход.

В приложении для созвона выберите камеру **solocam**. С `--preview` фильтр работает
постоянно, без ожидания потребителя.

### Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--cam "Имя"` | `Full HD webcam` | имя камеры в DirectShow (список: `ffmpeg -list_devices true -f dshow -i dummy`) |
| `--bg` | `#232a33` | фон: `#rrggbb` цвет или путь к jpg/png |
| `--below` | `0.8` | где линия отсечки: ниже плеч, в расстояниях «нос–плечи»; `0` — по плечам |
| `--cut` | `0.65` | запасная линия (доля высоты кадра), когда плечи не видны; `1` — отсечку выключить совсем |
| `--pose` | `yolo11n-pose.pt` | модель для поиска плеч |
| `--grow` | `9` | запас маски цели, px; больше — терпимее к резким движениям, но лезет кресло |
| `--feather` | `21` | ширина плавного края, px |
| `--hold` | `1.5` | сколько секунд держать последнюю маску, если цель потеряна |
| `--size`, `--fps` | `1280x720`, `30` | формат выходного потока |
| `--imgsz` | `640` | вход YOLO; `480` быстрее, маска грубее |
| `--model` | `yolo11s-seg.pt` | `yolo11n-seg.pt` быстрее и слабее, `yolo11m-seg.pt` точнее |
| `--preview` | | окно предпросмотра |
| `--no-vcam` | | не открывать виртуальную камеру (для офлайн-тестов) |
| `--src файл.mp4` | | видео вместо камеры (по кругу) |
| `--out файл.mp4` | | писать результат в файл |
| `--frames N` | | остановиться после N кадров |
| `--ui PORT` | `8765` | порт страницы настроек, `0` — без неё |
| `--crop-cut` | | кадр по линии отсечки |
| `--crop-body` | | кадр вокруг фигуры |
| `--crop-pad` | `0.15` | поля вокруг фигуры при кадрировании, доля её размера |

Переменная `SOLOCAM_FFMPEG` — путь к ffmpeg.exe, если он не в PATH и не winget-сборка
(её solocam находит сам).

### Панель в трее

`autostart.bat install` кладёт в «Автозагрузку» два ярлыка: сам solocam и панель
`tray\solocam-tray.ps1` (PowerShell + WPF, как у панели монитора AW3821DW). Иконка в трее
показывает состояние цветом: серая — простой, оранжевая — запуск, голубая — готов к звонку
(«Подготовить к звонку», с оставшимся временем), зелёная — идёт трансляция, красная — solocam
не запущен. Клик — панель с теми же настройками, что на странице, плюс предпросмотр;
правый клик — открыть страницу в браузере, запустить/остановить solocam, выйти.
Панель ходит в solocam по тому же локальному API. Клик мимо панели или `Esc` только прячет
её. **«Выход»** (в меню иконки и кнопка внизу панели) выключает solocam целиком: фильтр,
камеру **solocam** и саму панель. Чтобы оставить фильтр без значка в трее, есть
`autostart.bat stop` / `start` и пункты «Остановить / Запустить solocam».

### Страница настроек

Пока solocam запущен, настройки крутятся в браузере: `settings.bat` или
<http://127.0.0.1:8765> (доступна только с этого компьютера).

- **Фон:** цвет или картинка — перетащите файл на страницу; загруженные картинки
  остаются в галерее (папка `bg\`).
- **Кадрирование** (две независимые галочки): «по линии отсечки» — низ кадра встаёт на линию
  отсечки торса, пустой полосы фона снизу нет; «вокруг фигуры» — кадр приближается к вам
  и плавно ведёт за вами (до 3×), с настраиваемыми полями. Вместе — плотный кадр
  «голова и плечи».
- **Вырезание:** линия отсечки ниже плеч, запасная линия, запас маски, мягкость края,
  сколько держать маску при потере цели.
- **Предпросмотр** результата и кнопка «Перезахватить меня» (то же, что `r`).

Всё применяется сразу, без перезапуска, и сохраняется в `settings.json`: он главнее
параметров командной строки. Пока открыт предпросмотр, веб-камера работает, как во время
созвона.

### Автозапуск: камера всегда в системе

```bat
autostart.bat install            # ярлык в «Автозагрузке» + запуск сейчас, без консоли
autostart.bat install --crop-cut # то же со своими параметрами (запоминаются в ярлыке)
autostart.bat status | start | stop | remove
```

Права администратора не нужны: ярлык кладётся в папку Startup пользователя и запускает
`pythonw.exe`, консоли нет, вывод идёт в `solocam.log`. После входа в Windows камера
**solocam** есть в системе.

В простое (камеру никто не открыл) веб-камера свободна, видеокарта не считает, видеопамять
не занята, в памяти только лёгкий процесс на ~20 МБ (первые 2 минуты после созвона —
ещё дочерний с контекстом CUDA, ~0.3 ГБ видеопамяти). Во время созвона — около 0.5 ГБ
видеопамяти и примерно 40 % видеокарты.

### Проверка без камеры

```bat
run.bat --src clip.mp4 --out out.mp4 --no-vcam --frames 150 --bg green
```

На ролике с несколькими людьми в `out.mp4` должен остаться один на зелёном фоне.
Так же проверяется скорость: в конце печатается fps.

## Встраивание

### Google Meet, Телемост, Zoom, Telegram, Discord

Запустите `run.bat` (или автозапуск), в настройках приложения выберите камеру **solocam**.
Собственное размытие/замену фона в приложении выключите: фон уже заменён, а второй
фильтр только портит край.

### OBS Studio

«Устройство захвата видео» → **solocam**, как любая камера.

### Другие программы, NDI, файл

`--out файл.mp4` пишет результат через ffmpeg. Для любого другого приёмника замените
`cam.send(...)` в `solocam.py`: на каждом шаге `out` — кадр RGB на GPU, `1×3×H×W`, 0..1.

## Ограничения

- Фильтр не знает вашего лица. Если вы вышли из кадра и вернулись, а в это время в кадре
  был кто-то другой, цель может остаться на нём — нажмите `r`. Распознавание лица
  (InsightFace) не встроено: пока не понадобилось.
- При резком взмахе руки её край на 1–2 кадра обрезается: запас маски маленький
  специально, чтобы не тянуть кресло.
- Только Windows 11 и только NVIDIA (CUDA). На CPU не запустится.
- В тёмной комнате дешёвая вебка сама снижает частоту до 15 кадров/с и мылит картинку —
  это до фильтра. Свет на лицо решает.
